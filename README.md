# مِيقَات | Hidjri Calendar

تطبيق ويب عربي بالكامل لتنظيم المواعيد على أساس **التقويم الهجري أولًا**، مع عرض التاريخ الميلادي مرجعًا ثانويًا. يُنشر على GitHub Pages دون خادم أو مفاتيح وصول.

## الإمكانات المتاحة في النسخة الأولى

- واجهة عربية RTL متجاوبة للحاسوب والهاتف، مع مظهرين فاتح وداكن.
- تقويم هجري شهري وتاريخ ميلادي مقابل لكل يوم؛ البداية الحسابية افتراضيًا عبر `Intl.DateTimeFormat` بنمط `islamic-umalqura`.
- مصدر الدولة قابل للتغيير: الجزائر (الافتراضي)، السعودية، المغرب، تونس، بلد آخر.
- **لا يدعي التطبيق أن الحساب الفلكي أو الحسابي هو بداية رسمية مثبتة.** تظهر شارة «تقديري» للأشهر التي لا يُوجد تاريخ مسجل لها، وتُعرض روابط الشواهد بجانب ما ورد في السجل.
- جدول أعمال، مهام واجتماعات ومواعيد شخصية، أولويات، وقت، ملاحظات، إنجاز، تكرار شهري/سنوي هجري وسنوي ميلادي.
- الموعد المثبت بالهجري يعاد حساب موقعه الزمني عند تصحيح بداية الشهر. الموعد المثبت بالميلادي لا يتحرك.
- تنبيه المتصفح حين يكون التطبيق **مفتوحًا** مع إذن Notification؛ لا توجد إشعارات دفع من الخادم والتبويب المغلق لا تصله تنبيهات مضمونة.
- تصدير `JSON` واستيراده للنسخ الاحتياطية، وتصدير أحداث السنة القادمة بصيغة `.ics` للاستخدام في تطبيقات التقويم الخارجية. المواعيد الهجرية المكررة تُصدَّر كتكرارات ميلادية محسوبة، ولا تُتابع بعدها تلقائيًا تغيّر مطالع الهلال في برنامج التقويم الخارجي.
- تثبيت كتطبيق PWA وتخزين واجهة العمل دون اتصال بعد أول فتح؛ بيانات الأخبار والمصادر تحتاج إلى الإنترنت.

## الرصد والمصدر المرجعي

المرجع الوطني: [وزارة الشؤون الدينية والأوقاف الجزائرية](https://marw.gov.dz/).

مصادر المقارنة: [المشروع الإسلامي لرصد الأهلة](https://astronomycenter.net/?l=ar)، [تقويم أم القرى الرسمي](https://www.ummulqura.org.sa/en)، [وكالة الأنباء السعودية](https://www.spa.gov.sa/).

ملف `data/months.json` يحمل **عددًا محدودًا من بدايات الأشهر المنقولة بمصادرها**. مثال: أعلنت وزارة الشؤون الدينية والأوقاف غرة محرم 1448 يوم 16 جوان 2026 بحسب [الإذاعة الجزائرية](https://news.radioalgerie.dz/ar/node/88359). ويورد [المشروع الإسلامي لرصد الأهلة](https://astronomycenter.net/icop/jua48.html) الجزائر ضمن دول بدأت جمادى الأولى 1448 يوم 12 أكتوبر 2026؛ وهو **نقل في سجل دولي** لا يُعد البيان الجزائري الأصلي. أي تسجيل في الملف يحمل وصف `reported` ولا يُحوّل تلقائيًا إلى تصديق وطني نهائي.

يعمل `.github/workflows/pages.yml` يوميًا عند دعم GitHub Actions المجدولة:
1. يزور صفحات المصادر المعينة في `scripts/monitor.mjs`.
2. يستخلص **عناوين وروابط مرشحة** تتصل برؤية الأهلة ويضعها في `data/headlines.json`.
3. ينشر القائمة على الموقع من GitHub Pages بعد الفحص.

**لا يستخدم مسار الرصد الآلي استخراجًا دلاليًا لقرار دولة، ولا يحوّل أي خبر إلى بداية شهر معتمدة دون تحقق.** تختلف بنى المواقع وقد تمنع بعضها جلب محتواها؛ حالة الأخطاء ظاهرة في البيانات. ويمكن للمستخدم إضافة بداية شهر يدويًا مع الدولة، المرجع، تاريخ البداية، ورابط https، فتُقدَّم على الحسابات في متصفحه. لا تتزامن التصحيحات الشخصية بين الأجهزة. لبناء نظام تصديق آلي حقيقي يلزم محرك خلفي مُراجع بشريًا ومصادر رسمية ذات API أو بيانات منظمة وأرشيف قرارات يمكن تدقيقه.

https://scientifica007.github.io/Hidjri_Calendar/

بعد النشر افتح AppHub واختر بطاقة «مِيقَات — التقويم الهجري». راجع نجاح إجراءات النشر في تبويب Actions؛ رفع الملفات ليس دليلًا على نجاح النشر.

## التشغيل المحلي والفحص

```bash
npm run check
python3 -m http.server 8000
```

افتح `http://localhost:8000/`. الاختبارات تستخدم Node.js 20 فأحدث ومحرّك ICU لتقويم أم القرى. تشغيل مراقب المصادر `npm run monitor` يحتاج اتصالًا بالإنترنت.

## الخصوصية والقيود

- كل المواعيد والملاحظات والتصحيحات المحلية محفوظة في `localStorage` بالمتصفح نفسه. لا توجد حسابات أو مزامنة مشفرة بين الأجهزة.
- GitHub Pages استضافة ثابتة، فلا يمكنها تقديم تذكير مضمون بعد إغلاق الموقع. لتذكيرات الهاتف المنتظمة استخدم ملف `.ics` في تقويم يدعم التنبيهات.
- اليوم الهجري في واجهة التخطيط يعرض على هيئة تاريخ مدني يبدأ منتصف الليل؛ لا يحسم هذا بداية اليوم الشرعية عند غروب الشمس.
- التقويم الرسمي يمكن أن يختلف باختلاف البلد والإعلان الفعلي؛ لا تستخدم التاريخ المتوقع وحده لإثبات عبادة أو مناسبة شرعية.
- التواريخ المدعومة لتحرير المواعيد وتصحيح الأشهر: تقريبًا من 1400 إلى 1550 هـ.
- لا تخزن في المستودع تفاصيل مواعيد خاصة أو بيانات حساسة، فالملفات العامة للعناوين المرجعية فقط.
